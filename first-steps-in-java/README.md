# First Steps in Java

Die ersten Gehversuche — eine rohe Sammlung kleiner Konsolenprogramme aus der
Anfangszeit, bewusst unaufgeräumt als Lern-Archiv behalten. Vieles davon ist
später als eigenständiges Projekt sauber neu gebaut worden (siehe die anderen
Ordner im Repo); hier liegen die Originale.

## Was drin ist (`src/`)

- **Spiele & Simulation:** `GameOfLife`, `MasterMind`, `MinesweaperV2`, `Bingo`, `ZahlenRatenV2`, `Lotto`
- **Datenstrukturen von Hand:** `MyList`, `MyStack`, `SortMerge`, `SortRadix`, `ListeSortieren`, `Mengenlehre`
- **Anwendungen:** `Bibliothek`/`BibFixed` (Bücher & Zitate), `KinoV2` (Kino-Kasse), `Wörterbuch`
- **Krypto-Übungen:** `ChiffreMONO`, `ChiffrePOLY` (mono-/polyalphabetische Chiffren), `hydra` (Passwort-Abgleich)
- **ANSI-Spielereien:** `saos`, `style`, `cybersec` (farbige Terminal-Ausgabe)
- **Rechner:** `TaschenRechnerV42easy`/`Adv`

> Hinweis: Diese Dateien laufen einzeln, ohne Build-Tool — einfach die jeweilige
> `main` ausführen. Kein zusammenhängendes Projekt, sondern Übungen.
